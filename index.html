Published data

The browser never calls fantasy.premierleague.com directly. GitHub Actions downloads the FPL API server-side and publishes snapshots into this repository. It also builds a media-activity snapshot from public Google News RSS results. The app reads those same-origin JSON files, avoiding browser CORS restrictions.

Model parity

This build preserves the Google Sheets scoring model, while replacing SpreadsheetApp storage/UI with browser state.
